# Dispfics MVP

Yapay zekâ destekli futbol takım yönetimi için ilk ürün prototipi.

## Modüller
- Dashboard
- Aktif Kadro
- Oyuncular
- Transfer Merkezi
- AI Teknik Asistan
- Performans Analizi

## Çalıştırma
```bash
npm install
npm run dev
```
Ardından http://localhost:3000 adresini açın.

## Sonraki aşama
Supabase/PostgreSQL, kimlik doğrulama, gerçek oyuncu verisi ve OpenAI tabanlı teknik asistan entegrasyonu.
